## Status

User choices: models 48K, 128K and +2 (+2A/+3, 16K and Timex later); the user's ROMs copied to `~/.mimic/roms/spectrum/` (not committed) plus a stub ROM; Kempston, Sinclair (Interface 2) and cursor joysticks, the Kempston mouse, the Multiface 128 and the Interface 1 with Microdrives and RS-232; freely distributed timing test programs. Done: `cpu-z80` reports every M-cycle's address (`TimedBus::wait_states_at`) and, with `Z80::idle_cycles`, every internal T-state with the address on the bus (`TimedBus::idle`; all Harte tests check those addresses); `chips-sinclair::spectrum` (ULA timing for 48K and 128K, contention and I/O contention, floating bus, border in 4-T-state steps, flash, lazy picture, savestate); `machine-spectrum` (memory and $7FFD paging, AY at half the CPU clock, beeper/tape/AY mix at 48 kHz, keyboard, joysticks on ports and keys, Kempston mouse, LD-BYTES trap and PLAY on LOAD, `autostart`, SNA/Z80 snapshots in a Program slot, Multiface 128, Interface 1 with shadow ROM paging, Microdrive select register and status, panel RESET/MULTIFACE, debugger spaces cpu/ram/rom and chips ula/paging/ay, gfx views screen/bitmap/charset); `drives-other::spectrum_tape` (TAP/TZX, speed scaled for 3.5469 MHz, TZX stop blocks), `drives-other::microdrive` (byte-level tape loop: gap, preamble, data; write after a header; FORMAT's filler past a record), `media::mdr`, `media::cdt` TAP and block list (the TZX pause now begins with an edge — fixes the last bit of every block for CPC tapes too), `devices-input::KempstonMouse`, `PortKind::SpectrumJoy`/`KempstonMouse`, keymap. All three models boot with real ROMs and PRINT; a TAP built by the test loads with the trap and in real time (48K and 128K Tape Loader); the Fuse Test (frame length, contended memory/I/O, floating bus, LDIR, high-port contention, $7FFD/$3FFD reads) passes completely on 48K, 128K and +2; the Multiface 128 menu appears and returns on 48K and 128K; the Interface 1 formats a cartridge, saves, CATs and loads it back. Beta Disk with TR-DOS 5.01 and TRD images built 2026-11-03 (`beta.rs`, `chips-acorn::wd1772` as WD1793, four drives, writes through Save): La Velada runs with `RUN "PlayIt"` (loads, AY music); its `boot`, a disk tool that reads TR-DOS internals, saves memory over the disk and ends in Disc Error, reason unknown; a jump to $0562 presses PLAY (For Peace in YU, a 48K loader in RAM). Formatting writes nothing, SCL is not read, the Beta 48 and boot at reset are not built. A user-supplied TAP game loads and plays with its music (the user, 2026-11-03), which meets the gate's TAP point. Open: border timing beyond the Fuse Test (no border test program at hand: the 4-T-state step and its phase are this project's choice); SAVE to tape (no recording deck); the RS-232/network port has no host device; Microdrive timing is byte-level (programs that time the tape themselves are not covered); the +2's own quirks beyond the 128K's; snow (I in contended memory) is not drawn; Multiface port read values other than bit 7 unverified.
