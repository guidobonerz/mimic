## Status

The ZX81 passes its gate (`tests/tests/zx81_boot.rs`).

TRS-80, begun 2026-11-09 (user choices: Model I + III with the Expansion Interface FDC, 1771/1793, JV1/JV3/DMK read and write; an own charset; Model I first, then the Expansion Interface, then the Model III; the tests build their own media, the user checks real ones later). ROMs from the user in `~/.mimic/roms/trs80/`: Level I, Level II 1.2/1.3, Model III Rev C, three System-80 ROMs and a Model I/III diagnostic ROM. Done: `machine-trs80` Model I (Z80 at 1.774 MHz, memory map, 8 × 8 keyboard, 64 × 16 text with block graphics and the 32-column mode, seven-bit video RAM, own 5 × 7 font, RESET as NMI, stub ROM, savestates), the 500-baud cassette (pulses from a CAS image, CSAVE recorded from the ROM's pulses; timing measured from the ROM), host keymap; `tests/tests/trs80_boot.rs`: Level II boots to MEMORY SIZE? and READY, computes, SET draws blocks, CSAVE/CLOAD round trip. Expansion Interface (option `ei=on`, 2026-11-09): interrupt latch at $37E0 (40 Hz clock, the FDC's INTRQ, Z80 INT), drive select at $37E1 with motors running two seconds after the last select, printer status $37E8, an FD1771 at track level (`machine-trs80::fdc`, also built for the 1793: DMK-style tracks turning at 300 rpm, IDs and data marks found where they lie, record type bits, lost data, WRITE TRACK with the format codes, READ ADDRESS/TRACK) on the existing `media::dmk` images (DMK, JV1, JV3), four drive slots written back on flush; gate tests: Level II boots a JV1 disk the test builds (track 0 sector 0 to $4200), whose boot code writes sector 1 through the 1771 by polling DRQ/BUSY, and the image holds it; BREAK at power-on skips the disk boot, 48 KB then. Model III (model "3", 2026-11-09, `machine-trs80::m3`): 2.028 MHz, 14 KB ROM to $37FF (role "model3", Rev C), eight-bit video RAM, ports $E0 (interrupt mask/status, 30 Hz clock), $E4 (NMI mask/status: INTRQ, motor timeout, RESET), $EC (clears the clock, 32 columns), $F0-$F3 FD1793, $F4 (drive, side, WAIT, density), $F8 printer; WAIT on the data register lengthens the instruction until DRQ or the end; gate tests: BREAK at power-on → Cass? → Memory Size? → Model III BASIC computes; the ROM boots a double-density DMK disk the test builds (its INI loop under WAIT left through the controller's NMI) and the boot code writes sector 2 with OTIR under WAIT. Without a disk and without BREAK the ROM waits at "Diskette?" as the real machine does. Open: a real DOS disk (TRSDOS/LDOS/NEWDOS, the user's), the Model III cassette (500 and 1500 baud through its interrupts), Level I cassette (250 baud), the printer, the alternate character set and video wait states, double-sided Model I drives, video RAM snow, the System-80 clones (ROMs at hand).

## Backlog detail

- **Sinclair ZX81** (Phase 10): reuses `cpu-z80`; the CPU itself generates the display (NMI/HALT-driven, ULA counts lines), 1 KB/16 KB RAM, tape via ear/mic; ROM user-supplied.
- **Tandy TRS-80 Model I/III** (Phase 10): reuses `cpu-z80`; memory-mapped text screen with block graphics, keyboard matrix in the address space, cassette, Expansion Interface / FDC 1771/1793 floppies (DMK/JV1/JV3 images); ROMs user-supplied.
