## Status

User choices: 128K, 512K, Plus and SE as models of `machine-mac`; the original ROMs from the user (`~/.mimic/roms/mac/`: 128K 28BA61CE, 512K 28BA4E50, Plus v3 4D1F8172, SE B2E362A8); SCSI hard disks, DSK + DiskCopy 4.2, sound, SCC; System 6 disks later from the user. Done: `machine-mac` (memory map with overlay, video with RAM contention, VIA wiring, RTC with 20/256-byte PRAM, M0110/M0110A keyboard on the VIA's external-clock shift register, SE ADB transceiver with keyboard and mouse, SCC 8530 with DCD interrupts and the modified vector, NCR 5380 with SCSI-1 disk targets and pseudo-DMA, sound from the buffer at the E clock, interrupt switch on the panel, stub ROM, savestates, debugger spaces cpu/ram/rom), `drives-other::iwm` (IWM latch mode and write path, Sony 400K/800K drives with sense lines, stepping, tachometer, the 400K drive's PWM speed), `media::macdisk` (GCR 6-and-2 sectors with the three-checksum data field, zones, 2:1 interleave, raw and DiskCopy 4.2 images with write-back), `chips-cbm::via` external-clock shift modes 3/7 and CA2 input, `PortKind::MacMouse` (the Amiga mouse device with its own kind), keymap (Alt = Command, Windows = Option), monitor profile `mac`. All four models reach the disk icon with real ROMs (the startup sound plays); a disk the test builds (MFS volume, boot blocks with bbVersion $44xx) boots on all four through the IWM (400K on the 128K/512K, 800K on the Plus/SE), which checks the GCR checksums. System 6.0.8 (archive.org, 800K raw images) boots from floppy to the Finder on the Plus and SE; System 7.5.5 from SCSI images (archive.org BlueSCSI set, a user image) starts on the Plus and SE (4 MB) up to the extensions' alerts. Fixes found on the way: the Sony STEP line must clear within the driver's ~5 ms, SCSI disks report no unit attention, the Plus tells SCSI is present by $440000 not repeating the ROM, AppleTalk needs the SCC's Tx underrun interrupt and RR0 hunt bit, the Plus's Y2 is inverted against the device and the ROM counts one pixel per two phases, the SE's ADB transceiver auto-polls the last Talk in idle. Checked 2026-11-01 under System 6.0.8 and 7.5.5 by driving the machine through the debug protocol: the Plus takes mouse (axes and diagonals exact), menus and keyboard in the Finder, and reaches the 7.5.5 Finder with Shift held from about frame 1880 (needed: the image, set up for a Mac IIfx, loads code with the 68010 instruction RTD, so its extensions bomb with "illegal instruction" on a 68000, correctly). Fixes: VIA + SCC gave level 3, whose autovector is a bare RTE, a livelock whenever both were pending (the SCC now outranks the VIA); the mouse's quadrature steps 4000 clocks apart, as the ROM reads X2/Y2 late on diagonals; the SE's auto-poll reports a service request of another device (the mouse was dead after the last Talk had gone to the keyboard). A blank disk file takes System 6.0.8 end to end on the Plus (2026-11-01): HD SC Setup 2.0.3 initialises it, the Installer installs from the four 800K disks, it boots alone on the Plus and SE. Fixes: receiving pseudo-DMA stops at a phase change (HD SC Setup asks for more than a target sends and hung with status and message swallowed; sending keeps DRQ, the Plus ROM waits for it after a block); the disks report as "QUANTUM P40S 940-40-94xx" (from the tool's drive table) with MODE SENSE page $30 "APPLE COMPUTER, INC". Writes stay in the copy-on-write overlay until `flush_media` (slot 10 + SCSI ID); no frontend commits by itself. Open (gate): on the SE, 7.5.5 with Shift (no frame from 1700 to 2600 turned the extensions off; the ROM takes a key pressed around frame 1500 before its keyboard driver is ready) and Cmd-O in the 6.0.8 Finder (KeyMap is right, no window opened; the disk icon looks already open from the start); 1.44 MB images are refused by the floppy drives (no FDHD/SWIM); the ADB handshake (when /INT falls) and the SE's SCSI only checked as far as its ROM's scan; the 400K drive's speed curve is a linear stand-in; IWM bit-cell timing (every bit reaches the latch whatever the speed); copy-protected disks; the 2.5 MB Plus/SE RAM layout; the SE's second internal drive select (VIA PA4) unverified; serial ports have no host device.
