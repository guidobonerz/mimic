## Status

User choices: A310 + A440 first (with the A305 and A3000 as models; ARM3, ARM250, A5000, the A4 later); own ARM tests plus the ROM boot, as no Harte set exists for ARM2; ROMs from https://arcarc.nl/archive/ROMS/OS/ kept in `~/.mimic/roms/archimedes/`. Done: `cpu-arm` (ARM2 with its pipeline, abort rules and table 21's cycles; 30 own tests), `chips-acorn` (MEMC with translator, protection, DMA address generators, sound buffers, ROM overlay; IOC with timers, KART, interrupts; VIDC line by line, cursor, exponential DAC, stereo image; PCF8583 on I²C; WD1772 at sector level with ADFS images), `machine-archimedes` (keyboard controller with mouse, latches, RAM aliasing by page size, sound, savestates), host keymap by position, mouse in port 0. RISC OS 3.11 passes its POST on the A310 and reaches the Supervisor prompt and with `*DESKTOP` the Desktop (test `riscos_reaches_the_desktop`). The Magnetic Scrolls Collection (user's ADFs, E format 800K) runs from drives :0 and :1 on 4 MB (2026-11-02): `!collect-1` in the Desktop, Corruption to its opening text, which met the gate's ADFS point; mouse clicks through the input queue. Found with it: the IOC control register's C2 reads high with a disc in the selected drive (ADFS touches nothing else without; polarity from that behaviour), Read Address walks round the track (ADFS tells the format by the IDs it sees), type I status shows index pulses and spin-up, the motor stops after 10 revolutions. RTC RAM defaults to two floppies and ADFS ($C7, $45, sum in $3F, as `*CONFIGURE` writes them); it is not kept between runs, so language, monitor and mode stay 0 (Supervisor prompt, mode 0). Open: keyboard and mouse in a real window; disc change by Ctrl+D unchecked; writing to a disc not run on a real ADFS; timing is simplified (I/O 4 clocks, DMA charged per line, no refresh); serial, Econet, podules, printer, hard disc are not fitted; picture includes the border, so a mode shows with its margins (monitor `1084s-rgb` for the aspect: 16 MHz pixels are half as wide as a line pair is high); supremacy bit ignored, cursor position offset from the data manual's not checked on pictures.

## Backlog detail

- **Acorn Archimedes family** (added 2026-10-24 on the user's request, widened to the whole family 2026-10-27, Phase 24): A305/A310/A440 first, then A3000, A410/1, A540, A5000, A3010/A3020/A4000 (ARM250: ARM2 core with MEMC, VIDC and IOC on one chip) and the A4 laptop; new `cpu-arm` (ARM2, later ARM3 with cache, ARM250), MEMC (memory controller, logical-to-physical page mapping; MEMC1a with 4 MB per MEMC, two MEMCs on the A440/A540), VIDC (video and 8-channel sound; VIDC enhancer for VGA modes), IOC (timers, interrupts, keyboard serial link), the keyboard's own controller with mouse, WD1772 FDC with ADF (ADFS) images (the later models' 82C710/82C711 with 1.6 MB high-density disks), ST506 and IDE hard disks, podules later; RISC OS / Arthur ROMs user-supplied (RISC OS 3.x free for non-commercial use from RISC OS Open as an optional download).
