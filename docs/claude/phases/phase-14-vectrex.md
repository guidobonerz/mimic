## Status

User choices: core extension `Machine::vectors()` (beam segments with intensity, default none) next to a rasterised `FrameRef`, so debugger, preview and tests stay unchanged; the system ROM user-supplied in `~/.mimic/roms/vectrex/` plus an own stub; two controllers, overlays, light pen, 3D Imager; the 6809 with own per-instruction tests (no Harte set exists). Done: `cpu-6809`, `emu_core::vector`, `machine-vectrex`, `devices-input::vectrex` (controller, light pen), `devices-cartridge::vectrex` (PB6 banking), VIA shift-out modes 5/6. The 4 KB executive and Scramble run; Gravitrex (John Dondzila, 2002, 32 KB) reaches its title and, with button 4, the planet screen (2026-11-03, headless; sound and play not checked). The built-in Mine Storm plays with the 8 KB system ROM (the user's `Mine Storm (1982).vec`, in `~/.mimic/roms/vectrex/` since 2026-11-04, picked over the 4 KB executive): GCE title, PLAYER 1, mine field 1; button 4 fires and the joystick turns the ship (`mine_storm_plays`, `EMU_ROM_DIR`). Its loop is not locked to the 30 000-cycle picture window, so some windows hold no ship (segment counts vary 150–320 a window): the real game's rate also drops with the number of objects, not compared. All open items done 2026-11-11 (below).

## Backlog detail

- **Vectrex** (Phase 14): 6809 CPU (new `cpu-6809`), VIA 6522 (reuse from `chips-cbm`), AY-3-8912 (reuse from `chips-amstrad`), and a vector display: needs a vector frame type next to `FrameRef` (beam lines with intensity, phosphor decay in `video-crt`) — the debugger/preview contract then carries vectors or a rasterized picture; overlays; console panel: POWER, RESET.

User decisions 2026-11-11 for the open items: overlays as the user's own pictures (PNG per game in `~/.mimic/overlays/vectrex/`, named like the cartridge, transparent where there is no filter; nothing in the repository), phosphor persistence exact per segment, order persistence → overlays → protocol.

Done 2026-11-11: phosphor persistence. `emu_core::vector`: `Segment::at` (cycle from the frame's start), `VectorFrame::frame_cycles` and `style`, the rasteriser moved from `machine-vectrex/src/render.rs` to `emu_core::vector::Raster` (weighted deposit, tone curve; the machine's picture unchanged). `video_crt::phosphor::VectorPhosphor` (model in `crt.md`), profile field `phosphor_ms`, preset `vectrex` (the Vectrex's default monitor). Desktop, web and headless (`--crt`) draw vector frames through it. Savestate chunk `VECX` version 2 (segment times). `mine_storm_plays` now also finds the ROM in `~/.mimic/roms` (it skipped silently without `EMU_ROM_DIR`). Tests: 4 in `video-crt` (τ → 0 gives the raw picture, late lines glow into the next frame and fade, a still picture settles at its raw brightness, repeat and reset), 1 in `emu-core`, 1 in `machine-vectrex` (segment times in order within the frame).

Done 2026-11-11: overlays. `video_crt::overlay` (PNG, filter model in `crt.md`), `media_backends::overlays` (folder, name lookup, the built-in game's name), desktop (`--overlay FILE|none`, follows the cartridge on insert and eject), headless (`--overlay FILE|auto`), web (an uploaded PNG named like the cartridge, the "Overlay" choice, command `overlay`). The Vectrex's frames now say `OutputType::Rgb` (as `Monochrome` the CRT stage dropped every colour, also the 3D Imager's — found with the overlay). Tests: 2 in `video-crt`, 1 in `media-backends`, 1 in `emu-web`. Checked with an own test overlay (colour bands, a printed border) on Mine Storm's title through `--crt vectrex`.

Done 2026-11-11: beam segments in the debug protocol and the preview.
