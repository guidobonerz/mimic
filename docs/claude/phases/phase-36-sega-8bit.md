## Decisions (2026-11-19)

User: begin with the SG-1000 / SC-3000; models SG-1000, SG-1000 II, SC-3000, SC-3000H now, the SF-7000 disk unit later; tested with this project's own test cartridge (no game or BASIC images at hand; the user adds real ones later); one crate `machine-sega8` with models, the Master System and Game Gear as further models later. Mine: machine id `sega8`; `cartram=auto` gives an SC-3000 16 KB at $8000 for a cartridge of at most 32 KB; the SC-3000's shifted key legends assumed from the Japanese layout; reads where no chip answers return $FF (the real bus holds the last refresh byte).

## Status (2026-11-19)

Built (`machine-sega8`, `devices-cartridge::sega`, `PortKind::SegaJoy`, keymap `sega8`): M1 SG-1000 (Z80, TMS9918A, SN76489, two pads, PAUSE NMI, VDP /INT, cartridge mirrors and RAM, open bus, test cartridge `cart=demo`, savestates, debugger, overlays incl. `sprite_bounds`, graphics views), M2 SG-1000 II and PAL (TMS9929A, the CPU at 3.58 MHz as on the PAL SC-3000H), M3 SC-3000/SC-3000H (8255 PPI, 7 × 12 key matrix, pads as row 7, RESET key NMI, 2 KB work RAM, typing and paste through the keys), M4 the cassette (`drives-other::apple_tape` without motor control: PC3 out, PB7 in; recording and playback checked in a round-trip test). 11 unit tests. Source: Charles MacDonald's SC-3000H hardware notes.

Second block (2026-11-19, user: "mach mit den sega weiter"; scope chosen by the user: Master System, Game Gear, FM sound (YM2413), SG-1000 games on the SMS; own test cartridge; the BIOS optional). Built: M6 `chips-sega::vdp` (SMS, SMS 2 and GG VDP: mode 4 with scrolling and its locks, column mask, 64 sprites, zoom, overflow/collision, line and frame interrupt, V counter tables, H counter latch on TH, 224/240 lines on the SMS 2/GG, the SMS 1 quirks, the TMS modes for SG-1000 cartridges with the TMS colours, the Game Gear's 12-bit CRAM and 160 × 144 window; `sprites`/`sprite_bounds` overlays; 9 tests); M7 the models `mark3`, `sms`, `sms2` (`machine-sega8::sms`: Sega and Codemasters mappers with cartridge RAM, ports $3E/$3F/$DC/$DD, TH and region, PAUSE NMI, RESET button, optional BIOS (role `sms-bios`, 8 KB) handing over through $3E, the start without BIOS as it leaves the machine, a mode-4 test cartridge `cart=demo`, `devices-cartridge::sega::SmsCart` up to 4 MB with the copier header dropped); M8 the Game Gear `gg` (START and region at port $00, stereo at $06, BIOS role `gg-bios` 1 KB); M9 the YM2413 (`chips-yamaha::ym2413`, own implementation from the datasheet; instrument ROM: Okazaki's estimates from emu2413, MIT) at ports $F0–$F2, `fm=on|off` (default on for `sms` + `region=japan`); `chips-ti::Sn76489::sega` (16-bit noise) and per-channel levels. 13 new machine tests. Mine: the SMS/GG VDP is its own chip in `chips-sega` (the dependency rule forbids `chips-ti` there), RGB frames; the instrument ROM from emu2413 because no exact dump exists; the YM2413 has no damp phase and the OPL family's envelope rate pattern; no light phaser, Korean mappers or battery RAM file yet.

Open: real games and a BASIC cartridge (the gate), the BIOS with a real image, the SF-7000, ghost keys of the matrix, the refresh byte on unused port reads, the Terebi Oekaki tablet, the SK-1100 keyboard on the SG-1000 II; the Light Phaser, the Korean mappers, the cartridge RAM as a `.srm` battery file, the Game Gear's link port and its TMS-mode scaling, the SMS VDP's mid-line register timing, the YM2413's damp phase and measured envelope rates.
