## Status

User choices: II, II+ and IIe (unenhanced and enhanced) as models of `machine-apple2`; the original ROMs from the user (`~/.mimic/roms/apple2/`, Apple part numbers: II 341-0001…0004, II+ 341-0011…0015/0020, IIe 342-0134/0135, enhanced 342-0303/0304, character ROMs 341-0036, 342-0133, 342-0265, Disk II P5 341-0027 and P6 341-0028); DSK/DO/PO + WOZ, paddles/joystick, cassette, Mockingboard. Done: `cpu-6502` `Variant::Cmos65C02` (all 256 000 Harte `synertek65c02` tests; the undefined opcodes and decimal-mode dummy reads follow those traces; benchmark unchanged), `machine-apple2` (video scanner with floating bus, text/lo-res/hi-res/80-column/double modes, character ROMs or own font, language card, IIe memory switches and status reads, keyboard encoder with IIe auto-repeat, speaker, paddles/buttons, Mockingboard, stub ROM, savestates, debugger spaces cpu/main/aux), `drives-other::disk2` (P6 sequencer with its line order found by reading nibbles through the user's PROM; functional model without it; stepper with quarter tracks; DSK/NIB/WOZ write-back), `drives-other::apple_tape` (WAV play/record; the tape moves while the program listens), `media::a2disk` (6-and-2 GCR, WOZ 1/2), `media::wav`, `devices-input::apple` (`PortKind::AppleGame`), keymap (Alt = Apple keys, F5 = RESET), default monitor "tv". All four models boot with real ROMs, Zork I (DSK) boots on the II+ and IIe, a disk built by the test boots through P5 (with P6 and functional), cassette W/R works, hi-res colours checked through the composite stage. Open (gate): DOS 3.3 and ProDOS disks (none at hand), artifact colours against reference pictures (only the four hues checked), Mockingboard with real software, WOZ copy protections; the II+ keyboard layout (Shift-2 ") is not reproduced; no PAL (Europlus) models, no IIc/IIgs; RAM shows a simple power-on pattern; double lo-res aux colours unverified.
