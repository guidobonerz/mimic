## Decisions (2026-11-19)

User ("baue nun das megadrive"): the full Phase 37 scope in one block (Mega-CD and 32X stay later); tested with this project's own test cartridge (real games later from the user); one model `megadrive` with the region as an option and TMSS as an option. Mine: the master clock as the machine's time base (68000 ÷7, Z80 ÷15); the VDP as `chips-sega::mdvdp` and the YM2612 in `chips-yamaha` (own implementations from MacDonald's notes, Sega's manual and the YM2608 manual); 68000 → VDP DMA done at once with the 68000 frozen for the manual's transfer time; no VDP FIFO; the 6-button pad as `devices-input::MdPad` with a new `PortKind::MegaDrivePad`; host gamepad mapping South B, East C, West A, North Y, shoulders X/Z, Select MODE; the SMD halves' order decided by the "SEGA" header (MacDonald's code and other notes disagree); the X24C01's bit order assumed LSB first (unchecked).

## Status (2026-11-19)

Built: `machine-megadrive` (68000 `step_timed` with the board caught up on I/O, Z80 and VDP accesses; Z80 with bus request, reset and bank window; I/O chip with version, data/control, serial registers; TMSS lock and optional TMSS ROM `md-tmss`; SRAM by the header with $A130F1, X24C01 EEPROM by `save=eeprom`, both in the `.srm` battery slot; SSF2 mapper; RESET button; savestates; debugger with the 68000 and the Z80 as targets, VRAM/CRAM/VSRAM spaces; `sprites`/`sprite_bounds` overlays), `chips-sega::mdvdp` (planes, window, scrolling modes, 80 sprites with links, limits, masking, collision and overflow, shadow/highlight, H32/H40, 224/240 lines, interlace, DMA 68000/fill/copy, H/V interrupts, HV counter tables; 9 tests), `chips-yamaha::ym2612` (6 channels, 8 algorithms, feedback, detune, LFO, SSG-EG, timers, DAC, stereo, channel 3 special mode; 5 tests), `devices-input::MdPad` (3/6 buttons, time-out; 3 tests), `devices-cartridge::megadrive` (BIN/SMD, header backup RAM, SSF2 detection; 2 tests), the built-in 68000 test cartridge `cart=demo` (VDP set-up, sprite moved by pad 1, Z80 program keying a YM2612 note, PSG tone on A); 13 machine tests. Speed: the demo at about 3.7 × real time (release).

Graphics views (2026-11-19, user: "baue die grafikansichten für das megadrive ein"): `tiles`, `plane_a`, `plane_b`, `window`, `sprites`, `palette` (`chips-sega::mdvdp::gfx`, 2 tests, plus a machine test; checked with `polydbg gfx` on the demo).

Test ROMs (2026-11-19, user: "suche freie test-roms", then "ja, mach das"): Genesis Plus GX's `md_test.zip` in `tools/fetch-testdata.sh` (`testdata/md-tests`), runner `tests/tests/megadrive_tests.rs`. `memtest_68k` 13/13 after the open bus was built (before 6/13: unmapped addresses, the Z80 area without its bus, $A11100/$A11200, the status's top bits and the unused VDP ports read 0); the other 15 ROMs run and draw. Not fetched: the 240p Test Suite (itch.io), flamewing's 68k BCD verifier (source only), Nemesis' sprite masking and FIFO tests and r57shell's VDP tests (forum attachments).

Open: real games (the gate); VDPTEST's values against a real console (it prints raw HV counter values, no verdict); the VDP FIFO and DMA time slots by line, mid-line register timing, the mode 4 (Master System) display and the Power Base Converter; the YM2612's exact envelope and SSG-EG timing, its 9-bit DAC and ladder effect; the 68000's bus arbitration with the Z80's bank accesses; light guns (Menacer, Justifier), mouse, multitap; the TMSS ROM with a real image; the Mega-CD and 32X steps.

First real game (2026-11-20): *Flashback* (Europe) from the user's cartridge (not in the repo) runs without input through the publisher's logos and the whole intro film to its title menu, 4800 fields, no visible fault; `docs/screenshots/md-flashback.png` (field 3600, `--crt raw`) is in the README gallery. Not played: the headless frontend has no option for pad input.
